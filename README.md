# ProjectCSC - Smart Hospital \& Resource Allocation System



A simple, menu driven hospital management system written in C for the assignment.



What it does

* Registers new patients
* Assigns a ward and bed if the patient needs to be admitted
* Calculate the bill automatically
* Sorts patients into an emergency triage list
* Shows basic hospital analytics
* Saves patient records and bed status to text files



How it's built

* Written in plain C 
* All patients data is stored in arrays that share the same index



How to run 

1. Open main.c in Code::Blocks
2. Build and run
3. Follow the on-screen menu
